# GameShelf

Sistema web para organizar uma coleção de jogos: cadastrar, consultar e organizar títulos que você possui ou deseja jogar.

## Etapa 1 — HTML e Estrutura da Interface
- Estrutura HTML semântica
- Formulário de cadastro de jogo
- Listagem em tabela com pesquisa, filtros e ordenação
- Área de detalhes
- Publicação no GitHub Pages

## Entidade principal
Jogo: título, plataforma, gênero, ano de lançamento, desenvolvedora, status, nota, descrição e capa.
